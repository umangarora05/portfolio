# Umang Arora Portfolio

A responsive personal portfolio built with React and Vite. It presents Umang's
experience, education, projects, technical skills, achievements, and contact
details in a single-page layout.

## Features

- Responsive navigation with interactive profile photo card
- About, education, projects, skills, achievements, and contact sections
- Full project and certificate links
- Gmail compose links pre-filled with `umangarora2003@gmail.com`
- Live LeetCode activity when the stats service is available

## Tech stack

- React 18
- Vite
- Lucide React
- CSS with responsive layouts and theme variables

## Run locally

```powershell
cd frontend
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://localhost:5173`.

## Production build

```powershell
cd frontend
npm run build
npm run preview
```

## Project structure

```text
frontend/
  public/        Static images, certificates, and resume
  src/main.jsx   Application components and content
  src/styles.css Theme and responsive styling
```
